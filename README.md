# 🎓 ISEU Academic Bot (МГЭИ им. А.Д. Сахарова БГУ)

Telegram-бот нового поколения с встроенным WebApp для автоматической генерации готовых к сдаче **рефератов (DOCX)**, **докладов с речью** и **презентаций (PPTX)** строго по академическим стандартам Международного государственного экологического института имени А.Д. Сахарова БГУ (г. Минск).

---

## 🌟 Ключевые возможности

1. **Строгое соответствие стандартам МГЭИ им. А.Д. Сахарова БГУ и ГОСТ РБ:**
   - **Официальный титульный лист:** правильная шапка (Министерство образования РБ, БГУ, МГЭИ им. А.Д. Сахарова), выбор факультета (ФМОС / ФЭМ), кафедры, данных студента и научного руководителя, г. Минск.
   - **Параметры страницы:** формат А4, поля (левое — 30 мм, правое — 10 мм, верхнее — 20 мм, нижнее — 20 мм).
   - **Шрифт и абзацы:** Times New Roman 14 pt, полуторный межстрочный интервал (1.5), красная строка 1.25 см, выравнивание по ширине.
   - **Нумерация страниц:** сквозная арабскими цифрами по центру внизу страницы, титульный лист учитывается, но номер на нем не отображается.
   - **Библиографический список:** оформление по ГОСТ 7.1-2003 / требованиям ВАК Беларуси с реальными изданиями и правильными сносками в тексте `[1, с. 24]`.

2. **📊 Презентации нового поколения (.pptx):**
   - Современный широкоформатный формат **16:9** (widescreen).
   - Фирменная экологическая академическая палитра (глубокий изумрудный, мягкий мятный, белый, карточный дизайн).
   - Структурированные тезисы, инфографика и иллюстрации.
   - **Заметки докладчика (Speaker Notes):** к каждому слайду встроена готовая речь выступления от первого лица.

3. **🛡️ "Человеческий" стиль текста (Anti-AI / Защита от детекторов):**
   - Полный запрет на шаблонные фразы нейросетей (*«В современном мире...»*, *«Нельзя не отметить...»*, *«Является краеугольным камнем...»*).
   - Высокая вариативность длины предложений (burstiness).
   - Опора на законодательство Беларуси (Закон РБ «Об охране окружающей среды», Водный кодекс, ТКП, СанПиН, данные НСМОС РБ и Белгидромета).

4. **🖼️ Гибридный модуль изображений:**
   - Поиск реальных научных схем, диаграмм и фотографий в интернете (Wikimedia Commons, DuckDuckGo).
   - Автоматический fallback на генерацию через нейросеть при отсутствии аналогов.
   - Оформление подписей под рисунками строго по ГОСТ: `Рисунок 1 — Название рисунка`.

5. **📁 Клонирование стиля из присланного файла (Reference Matching):**
   - Отправьте боту готовый `.docx` или `.pptx` (методичку, эталонный реферат или презентацию с кафедры).
   - Бот автоматически извлечет шрифты, отступы, структуру разделов и обороты речи, после чего будет создавать новые работы **по их подобию**.

6. **✏️ Итеративное редактирование на лету:**
   - Получили готовый файл? Просто напишите боту в чат, что изменить:
     - *«Добавь во вторую главу расчет выбросов для Минска»*
     - *«Замени картинку на 3 слайде на схему очистных сооружений»*
     - *«Сделай заключение более кратким»*
   - Бот моментально пришлет обновленную версию документа!

7. **📱 Интерактивный Telegram WebApp:**
   - Удобный конфигуратор прямо в Telegram: выбор факультета с автоподгрузкой кафедр, ввод темы, настройка объема, переключатели картинок и анти-AI режима.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка конфигурации (.env)
Откройте файл `.env` и укажите ваши ключи:
```ini
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
GEMINI_API_KEY=ваш_ключ_Google_Gemini
GEMINI_MODEL=gemini-2.5-flash
WEBAPP_PORT=8080
WEBAPP_URL=http://localhost:8080
```
> 💡 *Ключ Gemini API можно бесплатно получить на [Google AI Studio](https://aistudio.google.com/).*

### 3. Запуск бота
```bash
python bot.py
```

## 📂 Структура проекта

```
iseu_academic_bot/
├── bot.py                  # Главный скрипт Telegram-бота (aiogram 3)
├── config.py               # Конфигурация и переменные окружения
├── webapp_server.py        # Веб-сервер для Telegram WebApp (aiohttp)
├── webapp/                 # Фронтенд WebApp
│   ├── index.html          # Интерфейс конструктора работ
│   └── style.css           # Стили в дизайне Telegram
├── core/
│   ├── gemini_client.py    # Асинхронный клиент Google Gemini REST API
│   ├── prompts.py          # Системные промпты, Anti-AI защита и стандарты Сахарова
│   ├── reference_parser.py # Анализ и клонирование стиля из загруженных .docx/.pptx
│   ├── image_service.py    # Гибридный поиск картинок (Wikimedia/DuckDuckGo/AI)
│   ├── docx_generator.py   # Генератор DOCX по стандартам МГЭИ и ГОСТ
│   ├── pptx_generator.py   # Генератор PPTX 16:9 с заметками докладчика
│   └── session_manager.py  # Хранилище сессий и итеративных правок
├── templates/
│   └── sakharov_standards.json # Параметры оформления, кафедры и факультеты
├── tests/
│   └── test_generators.py  # Автотесты верстки DOCX, PPTX и парсера
└── output/                 # Каталог готовых сгенерированных файлов
```
